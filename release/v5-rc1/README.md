# Resurrection V5 — RC1 release folder

Built from commit `b78e03b` (the code is identical to the fully tested commit `0983c38`; see `docs/V5-RC1-ACCEPTANCE.md`).
Not released, deployed or submitted. `SHA256SUMS` lists the checksums of the two zips (`sha256sum -c SHA256SUMS`).

| File | For | Open |
|---|---|---|
| `resurrection-v5-rc1.zip` | the owner | unzip, double-click **`Resurrection-V5-Start.html`**. Needs only a browser. Contains the game, the technical demo, the music page, the key-scene hub, the playtest build, the feedback form and the review documents. |
| `resurrection-v5-playtest.zip` | players | unzip, open `START-HERE.html`, then `Resurrection-V5-Playtest.html`. Needs only a browser. The play record stays in the player’s browser and can be downloaded or deleted by the player. |

Unzipped, the single files also work from a phone only if served: run `npm run v5:lan` in the repository instead.

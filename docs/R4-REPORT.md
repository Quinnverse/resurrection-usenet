## 5. 仍存在的风险

1. **没有真人玩过**。序章是否慢、对话是否有效、选择是否有分量、信是否“解释过度”，都是设计预期。
2. **中文**由作者撰写，没有母语审校。
3. **穿模**只做了对话镜头扫描，人物肢体穿插、道具穿墙没有逐一排查。
4. “绿色遮挡”：我只能确认默认镜头里埃莱娜后脑勺遮住琳这一处；如果 Owner 还看到绿色，请指出是哪一句。
5. 琳（June）在序章 E 的主动性仍以“说话”为主，走位较少。
6. 序章的厨房用同一套人物模型，埃莱娜 45 岁靠发色、发型、眼镜和衣服区分；没有表情与动作上的“年龄”。
7. P5 旧切片是已知基线失败（`V5-P5-BASELINE.md`），本分支没有碰它。

## 6. 预计游玩时长

**未知。** 目标 45–60 分钟。能给出的数字只有：脚本玩家（不读对白、一路跳过）整局约 10.7 分钟游戏时间；用键盘走完序章约 3 分钟、尾声约 40 秒（仅按键，不含阅读）。按 RC3 的经验，真人时间是机器人的 3–5 倍，但这是猜测。

解压 ZIP，双击 `Resurrection-V5.html`（Chrome / Edge / Firefox / Safari，电脑）。不需要安装、服务器或网络。若浏览器提供旧存档，选“新游戏”。试玩后回答 `PLAYTEST-QUESTIONS.txt`。

## 9. 真人试玩尚未验证的项目

1. 序章的节奏与情绪：玛拉的处境是否一开始就清楚；争吵是否“有道理的两个人”；空房子是否让人感到她曾在这里生活。
2. 恢复工具是否像“自己做的事”，而不是“看着它发生”。
3. 琳的出场是否有足够的铺垫；玩家是否想知道她们后来为什么决裂。
4. 光束、拍照、修链条：没有外部攻略能否完成（自动化只是读屏幕提示）。
5. 第六章是否让人感到埃莱娜的错没有被洗白；尾声是否是情感闭环而不是解释。
6. 总时长。
7. 真实 GPU、Safari、Firefox、真实手柄、真实手机、声音。

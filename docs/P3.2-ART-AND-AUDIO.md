# P3.2 art and audio inventory

## Provenance

**Everything is original to this project and created by code.** There are no image files, no audio files, no sprite sheets, no third-party fonts and no downloaded assets. Nothing needs a licence. The game and its art are covered by the repository licence (MIT, Quinnverse).

- Pictures: `frontend/p3/art.js` (palette, tiles, characters, props) and `frontend/p3/scenes.js` (scene composition, backgrounds, effects). They draw with `fillRect` and `drawImage` only.
- Sound: `frontend/p3/audio.js`, synthesised with WebAudio at run time (oscillators and a deterministic noise generator).
- Text: the interface uses system monospace fonts; nothing is embedded. Numbers on stamps use a 3 × 5 pixel font drawn in `scenes.js`.
- Inspirations are moods only (warm family stories, 1990s hobby games). No characters, scenes, dialogue or art are taken from any other work.

## Pictures

All pixel art is drawn at 320 × 176 and scaled up with `image-rendering: pixelated`.

| Group | Contents |
|---|---|
| Palette | One shared palette of about 70 colours: indigo and violet sky, warm gold, grass greens, earth browns, lavender rock, sand, plank wood, phosphor green/amber/cyan for the servers |
| Mara | Hand-drawn ASCII sprite, 14 × 24 px, 10 frames each way: idle ×2, run ×4, jump, fall, land, act (interact). Outlined, with scarf and ponytail |
| Tiles | Grass-top (3 variants), earth (3), cliff rock top and body (3 each), sand top and body, wooden deck, floating ledge (left, mid, right, single), bridge plank with truss, server floor, cable tray |
| World props | Tree, palm, bush, 4 flowers, shell, 2 signs (unread/read), sleeping cat (2 frames), crab (2), checkpoint flag (idle/active), shed door with blinking LEDs, bridge post with lantern, blueprint board, pier terminal (2), lighthouse, clouds (3), star (3 frames) and big star |
| Study | Bookshelf with coloured books, side table, cassette (glowing until taken), framed photo, game poster, desk, chair, CRT monitor (2 frames, breathing glow), sticky notes, red lamp (on/off), rug, window with golden sunset and swaying curtains, light shaft, drifting dust |
| Server room | Three racks (archive amber, lab green, mirror cyan, 2 blink frames each), hanging cables, scrolling grid wall, floppy disks, exit door, drifting data motes |
| Puzzle | Bridge fragments in build 2 style (rope and grey boards) and build 3 style (stone-capped planks and truss), stamps "B2"/"B3", glitch overlay for damaged data, static noise for missing data, four failure icons |
| Island | Cabin (growing), trees, flowers, bushes, console, photo stand, cassette player, star jar, note stand, sea with foam, star lanterns |

Animation and effects: idle breathing, run cycle, jump, fall, landing squash, interact pose; run dust and landing puffs; star burst; hearts when petting; swaying grass and flowers; drifting parallax clouds, three hill layers, sunset that deepens toward the sea; water ripples; glowing lanterns and CRTs; planks that drop in with a spark; screen shake on a fall; scene fades; island parts that grow up from the ground; typewriter text in the ending.

Reduced motion turns off sway, drift, shake, dust, fades, typewriter and shortens growth.

## Sound (all synthesised)

| Event | Sound |
|---|---|
| Jump, land, footstep | Short square sweep, soft thud, tiny tick |
| Star | Two rising bells; pitch climbs as the count grows |
| Secret found | Four-note rising arpeggio |
| Checkpoint | Two-note chime |
| UI click, door, power-up (CRT, terminal) | Click, two-tone door, rising sweep with noise |
| Book falls, cassette taken, cat | Thud, bell pair, meow glide |
| Open a server copy | Low hum with noise and two blips |
| Take / put back a fragment | Rising / falling blips |
| Wrong placement | Noise burst and falling saw, with a shaking piece and a coloured reason |
| Correct placement | Two bright notes, sparkles |
| Each plank | Rising pitch per plank, tiny noise |
| Bridge finished | Four-note rising chord |
| Typewriter | Soft blip every third letter |
| Island growth | Three-note chord, pitch rises each stage |
| Cassette on the island | A six-note hummed tune (slightly off-key on purpose) |
| Fall / splash | Falling saw / noise splash |
| Music | A quiet looping arpeggio per scene (study, world, server, island) |

Controls: a sound toggle and a volume slider, both remembered. Whether the sounds are pleasant to listen to is **UNVERIFIED**: automated tests only confirm that each sound was requested, not how it sounds.

# V5 key-line screenshots (chapters 2, 4, 6, 7)

From GitHub Actions run 44567880188 (commit e40b4ca, job "Browser end-to-end, V5 full game", 14/14 passed).
Headless Chromium, WebGL through SwiftShader (software GPU). Taken during the two full automated playthroughs
(`scene-en-*`: English, first set of choices; `scene-zh-*`: Chinese, other choices) about 8 frames after each key line
starts, once its subtitle has faded in. The file name is the line's text key (see `docs/V5-SCRIPT.md`).

What they show: the expression set for that line on speaker and listener, the camera the director chose, the scene.
They are frames from a test run, judged only by the developer. No player has seen them.

Changes made from earlier screenshots of these lines: per-line faces and resting eyelids (49a61e9), the porch
two-shot and June's face on the porch (49a61e9), a soft face light in dialogue close-ups so June is not backlit on the
porch and the 2004 beach (a9a3358).
